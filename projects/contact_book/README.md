# Contact Book

A simple command-line contact book written in Python.

## Features

- Add contacts
- Show contacts
- Search contacts
- Delete contacts
- Automatically save contacts to JSON
- Load contacts from JSON when the program starts

## Requirements

- Python 3

## How to Run

Run the program from the terminal:

```bash
python contact-book.py
```

## Example

```text
1. Add contact
2. Show contacts
3. Search contact
4. Delete contact
5. Exit
Choose an option: 1

Name: John
Number: 123456789
Email: john@example.com
```
