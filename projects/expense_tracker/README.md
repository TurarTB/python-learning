# Expense Tracker

A simple command-line expense tracker written in Python.

## Features

- Add expenses
- Show expenses
- Calculate total expenses
- Save expenses to JSON
- Load expenses from JSON

## Requirements

- Python 3

## How to Run

Run the program from the terminal:

```bash
python expense-tracker.py
```

Example:

```text
1. Add Expense
2. Show Expenses
3. Show Total
4. Exit
Choose an option: 1

Amount: 25.50
Category: Food
Description: Lunch
```
